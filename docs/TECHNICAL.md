# 기술 문서

## 문자 인코딩과 글꼴
- 게임 텍스트는 Shift-JIS입니다. 한글은 쓰이지 않는 SJIS 코드에 한글 글리프를 배정하는 방식으로 넣었습니다(`tools/charmap.py` → `work/charmap.json`, 한글 문자 → SJIS 코드).
- 글꼴은 LINKDATA 안의 글리프 아틀라스 텍스처 두 장(00032 = 12px, 00033 = 14px)이며 `tools/fontpatch.py` 가 해당 코드 위치에 한글 글리프를 그립니다.
- 제어 코드: `ESC C?`(색상), `ESC P?`(버튼 아이콘, ?는 0-9/A-Z), 색상 끝 `{R}`, 줄바꿈. `tools/textcodec.py` 가 `{C5}` `{PB}` 형태로 변환합니다.

## 실행 파일(EBOOT)
- 복호화한 EBOOT의 SJIS 문자열을 추출합니다. 문자열 사이에 NUL이 없는 경우가 있어, `.data` 영역(파일 오프셋 0x3FF5E0–0x47A904)의 정렬된 모든 u32 중 `.data` 를 가리키는 포인터를 찾아 그 위치에서 디코드하는 방식으로 누락분을 보충했습니다.
- 번역이 원문보다 길면 새 영역에 쓰고 해당 문자열을 가리키는 포인터를 모두 바꿉니다(VBASE = 0x08804000 − 0x54).

## LINKDATA
- `tools/linkdata.py` 로 아카이브를 읽고 씁니다. 스테이지 메시지는 64바이트 고정 슬롯(최대 63바이트)이라 제자리에 덮어씁니다.

## 그림 글자(ktex)
- `tools/ktex.py` 로 4/8bpp 팔레트 텍스처를 읽고, `tools/imgpatch.py` 가 `trans/images.json` 의 지시(지우기·인페인트·글자 그리기)를 적용한 뒤 원래 팔레트로 재양자화합니다. 크기와 팔레트는 그대로입니다.
- 여러 CLUT를 쓰는 아틀라스(00030)는 화면마다 팔레트가 달라, 에뮬레이터에서 얻은 팔레트로 편집하고 요소별로 원래 쓰던 인덱스만 사용합니다. 장 이름 라벨은 인덱스 0(투명)~15(글자 중심)의 깊이 단계로 저장되므로 거리 변환으로 깊이 맵을 만들어 씁니다.

## 동영상 자막
