# 진·삼국무쌍 MULTI RAID 2 한글화 번역 지침

## 작업 방식
- 입력: `work/tr_in/<배치>.json` — `[{"id": 정수, "jp": 원문, "max": 최대바이트, "ctx": 메모}, ...]` (게임 내 순서대로 정렬되어 있어 앞뒤 문맥 참고 가능)
- 출력: `trans/parts/<배치>.json` — `{"<id>": "번역문", ...}` (모든 id 빠짐없이)
- 출력 후 반드시 `python -I tools/check_batch.py <배치>` 실행 → 오류 0이 될 때까지 수정.
- 외부 번역기/웹 사용 금지. 직접 번역.

## 바이트 규칙 (매우 중요)
- 한글 1글자 = 2바이트, 반각 ASCII(공백, 영숫자, `, . ! ? ( ) - : / % +` 등) = 1바이트, 전각 기호(…「」『』・―～※●★○→ 등) = 2바이트.
- `max`는 절대 초과 금지(검사기가 계산). 넘치면 줄이거나 다른 표현으로.
- 띄어쓰기는 반각 공백(1바이트)만 사용. 전각 공백 `　` 사용 금지.
- 문장부호는 반각 `, . ! ?` 사용. 말줄임은 `……`(전각) 또는 `...` 둘 다 가능, 원문이 `……`면 `……` 유지.
- 원문 `！　` 처럼 문장 사이 전각 공백은 반각 공백 하나로.

## 제어 코드 보존
- `\n`(줄바꿈), `{C4}` `{C5}` `{C6}`(색상 시작), `{R}`(색상 끝), `{P0}` 등(아이콘)은 그대로 유지.
- 색상 코드는 감싸던 단어(인명/지명)를 그대로 감싸도록 번역문에서 위치 조정.
- `%s` `%d` `%2d` 등 서식 지정자는 개수·순서 그대로 유지(순서 바꾸지 말 것). 조사는 `%s`이(가)처럼 쓰지 말고 문장 구조를 바꿔 자연스럽게(예: `%s 획득!`, `%s의 공격`, `%s 격파!`).
- 줄 수: 원문 줄 수 이하. 한 줄 길이는 원문 해당 줄의 표시 폭 이하(한글 1자 = 전각 1자 폭, 반각 문자는 약 0.5자 폭). 검사기가 폭을 검사함.

## 문체
- 무장 대사: 사극/무협 어투. 원문의 말투(존댓말·반말·노인 말투·고압적 말투)를 살릴 것.
  - 예) 〜でござる → ~이옵니다/~입니다, 〜じゃ(노인) → ~구나/~느니라, 朕 → 짐, 我/某 → 나/이 몸, 貴様 → 네놈, 殿 → 공/님.
- 시스템/메뉴: 간결한 명사형. (예: 出撃 → 출격, 戻る → 뒤로, 決定 → 결정, はい/いいえ → 예/아니오)
- 설명문: ~한다/~합니다 중 원문에 맞춰 통일(아이템·스킬 설명은 "~한다/~하는" 간결체 권장).

## 고유명사
- 인명은 `trans/names.json`을 따른다(한국 삼국지 관례 한자음). 특수 글리프 문자(①③⑥㍉ 등)는 `trans/special_glyphs.json`의 한자로 해석(예: 許⑥=許褚=허저, 張③=張郃=장합, ①統=龐統=방통, 賈④=賈詡=가후, 女㍉=女媧=여와, ㌃邪=辟邪=벽사, 下⑲=下邳=하비, ㌶城=鄴城=업성, 井㎎=井陘=정형, 臨㎝=臨淄=임치).
- 지명: 한자음(洛陽 낙양, 汜水関 사수관, 虎牢関 호뢰관, 赤壁 적벽, 長坂 장판, 合肥 합비, 夷陵 이릉, 五丈原 오장원, 官渡 관도, 樊城 번성, 許昌 허창, 建業 건업, 成都 성도, 白門楼 백문루, 崑崙 곤륜, 宛城 완성, 石亭 석정, 江陵 강릉).
- 국가/세력: 魏 위, 呉 오, 蜀 촉, 漢 한, 秦 진, 楚 초, 周 주, 仙界 선계, 妖魔 요마.
- 편/장: 覇王編 패왕편, 妖仙編 요선편, 序章 서장, 第一章 제1장, 終章 종장, 始 시작, 終 끝.
- 몬스터/거대병기: 辟邪 벽사, 天禄 천록, 窮奇 궁기, 霊亀 영귀, 三首大鷹 삼수대응, 火光獣 화광수, 黒龍 흑룡, 蜀龍 촉룡, 魏鳳 위봉, 呉虎 오호, 妖獣 요수, 魔獣 마수.
- 펀자 표기 X: `真・三國無双` → `진·삼국무쌍`.
